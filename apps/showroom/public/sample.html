sample.html — 一行 <script> 嵌入商品卡

這是一個沒有框架、沒有建置流程的純 HTML 頁面（例如舊的 JSP / jQuery 頁面）。 只要載入 momo-card.iife.js 就能使用 <momo-product-card>。 頁面刻意加了會汙染 h3 / button / img 的全域樣式，用來驗證 Shadow DOM 隔離。

① 同步模式：card-id

資料來自共享 Store。請同時開著 Showroom 編輯器修改卡片，這裡會即時更新； 在這裡按 ♡ 收藏 / 🛒 加入購物車，Showroom 也會同步。（BroadcastChannel + localStorage）

② 靜態模式：data JSON attribute ＋ 主題覆寫

適合 SSR / CMS 直接輸出 HTML；不連 Store、不同步。外層以 --momo-card-* CSS 變數換成藍色、直角主題。

③ 宿主自訂 Plugin：雙 11 角標（不修改卡片原始碼）

下方卡片的資料帶有 extensions.double11。plugin 尚未註冊時被安全忽略； 2 秒後頁面呼叫 MomoCard.registerPlugin()，所有卡片自動重繪出角標。
